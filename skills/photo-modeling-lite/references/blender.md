# Blender执行接法

先发现部署者实际 Blender 可执行文件与版本，再用其绝对路径执行；便携包不包含 Blender，也不假设安装目录。

新任务用后台命令：

    blender --background --factory-startup --python build.py

已有工程先以副本打开，检查对象、相机、材质和修改器；禁止默认清空用户工程。每次后台运行用有超时/日志的已有执行器，不启动可见窗口或安装新组件。工厂配置避免本机旧插件干扰，不代表已迁移的插件全兼容。

建议在build.py顶部集中PARAMS：单位、原图尺寸/裁剪、部件框、厚度、截面、倒角、相机。近正视平面只用一套s和中心坐标映射；透视图用相机投影验证，不能逐物体扭曲来贴图。对锚点需要像素测量时，可用bpy_extras.object_utils.world_to_camera_view：u=co.x*W，v=(1-co.y)*H；渲染百分比和裁剪要计入。

布尔先检查实际孔洞和切割器贯穿，保留可编辑源；线脚使用沿路径截面或明确斜接拓扑；圆头薄板不要以受厚度钳制的倒角冒充平面圆弧；玻璃与门扇、墙体分别保持真实制造边界。

先低分辨率同角度渲染，重大形体通过后再出最终分辨率。无论CPU/GPU，用真实日志报告耗时，不把GPU名称当作实渲成功。材质渲染作为最后检查，不增加无依据的装饰。

compare.py 需要部署者自己的 Python + Pillow；先查现有依赖，不自动 pip 修改软件环境。无 Pillow 时使用宿主已有图像工具并排检查。
