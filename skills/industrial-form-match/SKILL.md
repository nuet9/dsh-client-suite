# 工业概念白模对形

把一张图当作一台相机拍到的投影。图里可以量到外缘、交点、宽度和遮挡。厚度、背面和真实尺寸通常需要假设。先让同一台相机能解释多个部件，再花时间做细节。

## 1. 给图定一个可复现的坐标系

在显示方向正确的工作副本上取点。手机 JPEG 先按 EXIF 方向转正，包括镜像方向。可用 `--clockwise 0` 先导出一张取点底图。像素原点在左上，向右、向下为正。保留原图、显示画幅、工作旋转和裁框，后续测量和回投都用同一套坐标。

对笔直、对称的主体，取相距较远的上下两道截面，用左右轮廓中点定主轴。另留中段的一道可辨截面做复核。`--axis-check` 只测该点到拟合轴的带符号距离。如果中段偏离超过取点把握，先查遮挡、截面偏心、透视或轴线选择。盒状件可用独立长棱和可见端面复核。对象本身斜置或弯曲时，选稳定基准并保留设计姿态。转图只校正画面内倾角，转好再裁切。见[转正工具](scripts/align_reference.py)。

## 2. 量能决定造型的位置

先量顶、底、左右极值，再量几个真正改变轮廓的截面。每个截面记下高度、左右边界、中心和宽度。附件则记录根部、末端、转折、露出主体的宽度，以及谁挡住谁。暗部看不清时，可临时提亮副本辨认边缘，保留原图作最终对照。选点不确定时给一个区间。

以主件的稳定宽度或总高作为比例单位。调相机前标出拟合点 `fit` 和留出点 `check`。后者可选另一端转折、附件末端或清晰的空隙边界。量净空时，在约定的同一截线上分别标出两侧边缘。记录原图能支持的取点误差。若把某个留出点用于下一轮调形，记录这一变化，再用其他仍独立的点复核。

## 3. 在 Blender 里对位置

先建低细节主件，建立参考相机。先对画幅、主轴倾角和主体占画面的比例，再用端面露出量、前后棱的间距定俯仰、方位和透视强弱。可先用正交相机估比例。有明显近大远小时用透视相机核对。原图裁切过时，光心可能偏离裁图中心。

一个二维点限定一条视线。对平面侧板，先设定板面的位置和朝向，再把轮廓点的相机射线与该平面求交。对旋转体，用多个高度的宽度估计截面，再从相机中复核。圆孔和圆杆端面随三维朝向自然投影成椭圆。对弯曲附件同时看外轮廓、接触点和遮挡次序。单张图无法唯一解出深度，把推定深度留成可调参数。

若使用简化透视坐标，可设相机在 (0, −D, 0)，朝 +Y，看向右为 +X，向上为 +Z。转正裁图中的光心为 (cx, cy)，像素焦距为 f。为像素 (u, v) 指定所在平面 Y=y 后，有 X=(u−cx)(D+y)/f，Z=(cy−v)(D+y)/f。其他相机姿态使用相机矩阵或射线求交。光心、焦距和距离均属于相机假设，像素取点本身无法确定它们。

## 4. 判断该改相机还是改模型

用参考相机输出带透明背景的白模或前景遮罩。把渲染与参照放回相同画幅、裁切和比例。只转正了工作图时，按记录补偿一次倾角。用[轮廓对照工具](scripts/compare_contours.py)叠图。透明底或清晰遮罩可直接提取轮廓。不透明参考图可手描关键可见边，先比较最影响识别的局部。青线表示参考，橙线表示模型，重叠处为白色。

同一组锚点分别在两图上取坐标，读取渲染相对参考的横纵偏差。把已参与拟合的点与独立留出点分开看。检查局部宽度或净空时，还要看两端之间的测距变化。只有部件平移时，两端可以一起偏而间距保持正确。修错尺寸会引入新的偏差。

| 对照时看见什么 | 优先检查什么 |
|---|---|
| 顶沿、底沿、附件末端一起朝同一方向偏 | 画幅原点、裁切、相机平移或横滚 |
| 主轴对齐，多个近端都偏大、远端都偏小 | 相机距离与焦距，结合端面露出量一起判断 |
| 上下端都对，中段逐渐偏宽 | 截面尺寸和锥度。检查中段两侧偏差是否对称 |
| 主体已对，只有侧板太宽或圆端面太扁 | 部件的朝向、深度与厚度，保留当前参考相机 |
| 正面轮廓对了，斜看把手悬空 | 固定主体，先查两端根部与各自接触面的距离。支座贴合后，再判断伸出量与净空 |
| 轮廓吻合，白模平面上却冒出暗三角 | 查面法线、平滑边界和倒角，再决定是否动轮廓 |

每轮先改能解释最大可见偏差的一组参数，沿用同一画幅复渲，观察留出点与主轮廓的变化。大形稳定后再处理倒角和折边。用一张斜视检查厚度、遮挡与连接。单图深度仍有多种解释时，把选择的假设写清楚。

## 5. 交付前按零件检查可编辑性

重新打开交付的工程，以设计意图给各零件分类。外壳等应当封闭的实体用 `solid`，故意单面的装饰片用 `sheet`，确认属于辅助物体才用 `skip`。不确定时保留 `review`。用[网格检查工具](scripts/check_mesh.py)检查当前视图层内修改器生效后的网格，报告逐件列出开放边、退化面和面朝向冲突。实体有开放边要定位。单面片允许预期边界，仍需核对边界位置和法线。未分类零件保留待查状态。

检查结果有异常时，定位到对应部件，在工程副本上修正并重跑。重点是可编辑性时，再在临时副本上做一次代表性的编辑，例如调整把手伸出量，检查接缝和修改器结果，然后回到交付工程。保存可编辑工程、同视角对照和斜视图，说明残余偏差与推定部分。[检查用法与音箱示例](references/checks.md)包含标注格式、报告解释和 Blender 后台命令。

## 例：提手音箱

在壳体中段量左右边，在同一竖线上量壳顶到提手下沿的净空。样例中壳宽在两张图上都是 137 px，净空却从参考的 43 px 变为模型的 36 px。提手左缘向右偏 5 px、下沿向下偏 7 px；因此先检查提手位置，不改壳体宽度。这些数是已标注样例的读数，不是容许误差或新任务的拟合目标。

旋转角以顺时针为正，逆变换回到按 EXIF 展开的显示图。不能沿用其他物件的角度、裁框或像素阈值。转正产生的透明边角不是物体轮廓；外部软件若丢失画布标签，须明确忽略透明通道或提供物体遮罩。没有可靠参考边时仅供视觉定位。区分坐标换算、人工取点的不确定性和模型投影偏差；单张图上少数点吻合不能证明整模精度。
