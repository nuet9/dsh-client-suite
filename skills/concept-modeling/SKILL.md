# 参考驱动概念建模 · v1.1

**形准优先于精度；两项独立验收。** 形准回答“是不是参考里的这个造型”；精度回答“以约定距离看，曲面、边缘和交接是否成立”。轮廓偏了，增加细分没有价值；轮廓准了，也不能用平面投影冒充有深度的部件。

## 开工：确定对什么负责

- 默认交付可编辑的静态单体与中性白模。读用户指定软件版本、审看距离、参考图和可改范围。未指定镜头时，用原图完整构图审形，加一张关键部位近景审精度。工具箱照片任务的默认 Blender 版本不继承。最小验证后台接口与保存路径，独立另存，不覆盖现场工程。
- 多图先区分同一物件的不同角度和仅供借鉴的风格图，指定一张造型主参考。记下决定辨识度的 3–5 项特征，标明「必须对准／允许设计／无证据」。无尺度用比例，不猜实物尺寸；背面未知可做一致的外观补全，不冒充复原。若只有文字，先明确关键比例与轮廓方案，以定下的方案验收，不能宣称与不存在的参考吻合。
- 分开估首个可审白模与精修交付的时间；首稿暴露新问题时更新估时。普通自检自行推进，不等用户逐关批准；仅设计意图冲突或必须改变范围时询问。

单图工业道具新建或修形时，先加载专项技能 `industrial-form-match`。转正副本按 EXIF 取点，用独立截面复核主轴；同镜头对照区分拟合点和留出复核点，并分别量部件位移与净空。复杂照片没有可靠轮廓时先标关键可见边，不自动猜边。重开交付工程后，按实体、单面片、待判和辅助件逐件查网格。三项工具与音箱用例见专项技能内的 `references/checks.md`；拓扑结果不能替代下面的斜视和近景验收。

## 一、形准：先锁镜头，再锁形

1. 在参考上标出整体包围框、主轴和 6–12 个可稳定辨认的点或截面：最宽处、肩线、转折、悬挑端点、开口边界等。至少选一处轮廓**以内**的负空间。记录方式从简，写在脚本或对照图上即可。模糊边缘标区间，不把高光当轮廓。
2. 先搭大体块，用长边汇聚、平行边、可见顶面宽度及圆截面椭圆率判断透视和视角。固定画幅，等比缩放；以分散在不同部位的地标校准相机。比较相同画幅的边线叠图或同尺度并排图，实际打开看，不凭脚本退出码判断。
3. 按“大轮廓 → 截面变化 → 内部留白与遮挡 → 部件位置”检查。整体同向漂移先查镜头；整体吻合但一处突出量错误，回改局部。锁定相机后保留该视角供以后回归。必要时记录最差地标偏了多少像素及方向，同时写明主体画面高度；不把像素差折算成整体还原率。
4. 转到斜视检查：剪影相似的薄片、厚块、孔洞和凹窝，在转动时应有不同的内缘、遮挡与视差。不要用单视角拉伸、黑材质或封底浅窝伪造开口；看不清的后方只做必要外观层次。任何高辨识特征类型错误、主比例明显漂移、离开主镜头就失去厚度，**退回形体稿**，不进入精修。

## 二、模型精度：按最终观看尺度分配几何

- 先挑一个最容易露馅的部位做样件，例如壶嘴与壶身的交接或穿孔灯罩的卷边。以目标近景的实际输出尺寸查看，再决定其余同类部位的分段和倒角。大圆角与薄板折边不能套同一半径；重复件共享截面或实例，不抹掉参考里的不对称。
- 对轮廓有贡献的弧线用真实曲线或足够分段的网格；靠厚薄、视差或遮挡辨认的细节做几何。细分后轮廓外扩或收缩要回原镜头检查。平面保持平、硬折保持利落，连续曲面不留意外折痕。白模任务不靠颜色、图案、噪点或暗光补精度。
- 用中性漫射光看大体积，用斜向长条高光扫最难的曲面和交接处，再看局部线框。目标近景中可见弧线折段、布尔夹痕、波浪高光、端面黑斑、相邻面闪烁、部件浮离，均不能报精修完成。沿边转动仍有折角先修截面或采样；轮廓平滑而高光断裂再查拓扑与法线。只对需要的区域加密，不以面数、全四边面或高清渲染代替质量判断。
- 分件按造型和编辑需求命名；保留关键曲线、修改器或可编辑控制面，不强制所有部件程序化。按物件性质检查重复面、退化面、法线和意外开边。开放薄片不按封闭实体误判。危险题材限非功能视觉道具，不交付实物尺寸、功能内构或制造资料。

## 三、交付：让别人能复核

保留可编辑工程、同镜头参考对照、独立斜视、关键部位近景；后三项可合成一张审看板。重开最终工程，检查依赖、对象可编辑性和相机；不默认另做 UV、材质、导出或动画。主镜头检查形准，斜视与近景检查精度，重开检查工程，三者不能互相代替。

每轮只处理最影响读形的 1–3 处，留下“问题 → 改了什么 → 哪张图说明改善”的短记录。两轮同一缺陷不见改善，说明证据缺口或改换方法的具体理由。收尾分别写「形准：通过／未通过／不可判」「精度：通过／未通过／不可判」，各给一项实际图证和剩余偏差。任何一项未过或不可判就标**阶段稿**，区分真实用时与剩余估时，不拿自评分当验收。
